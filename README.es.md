# 🔬 Proyecto Destacado

## YEGI — Plataforma de Resumización con IA

Plataforma web y API para resumización de artículos científicos usando LLMs y SLMs.

### Características
- Extracción de texto desde PDFs científicos
- Pipelines de preprocesamiento NLP
- Inferencia local con Ollama
- Arquitectura REST API con FastAPI
- Optimización de hiperparámetros para mejorar la calidad de los resúmenes

### Tecnologías
Python · FastAPI · Ollama · PyTorch · NLP · Docker · PostgreSQL
